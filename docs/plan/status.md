## How to resume a workflow run here

The Workflow tool caps concurrent agents at CPUs − 2 per run (2 on this 4-CPU machine), so runs are split by `args.subset` and launched side by side. A run's journal is `<session>/subagents/workflows/<runId>/journal.jsonl`; `resumeFromRunId` replays finished agents when the script and args are unchanged. Page fetches are refused by the environment's network policy; web search works.
